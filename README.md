# fix_loop

Project 4 from the Loop Engineering crash course.

## Run

```powershell
.\run.ps1 -Mode good
.\run.ps1 -Mode bad
```

## Roles

- `skill.md` — fix steps
- `implementer.js` — drafts the fix
- `reviewer.js` — grades PASS/FAIL
- `run.ps1` — the loop

## Done when

Good fix → PASS + PR. Bad fix → FAIL with reasons, no PR.
